# ExoHarness v0.1.0 — Linux public preview

A Rust AI agent framework with a self-hosted user portal, administration console, MCP and Skill integration, persistent execution records, and signed file delivery.

## Download

Use `exoharness-v0.1.0-linux-x86_64-gnu.tar.gz`, not GitHub's automatic source archive, to run the prebuilt service. Download `SHA256SUMS` alongside it and check the archive before extracting:

```bash
sha256sum --check SHA256SUMS --ignore-missing
tar -xzf exoharness-v0.1.0-linux-x86_64-gnu.tar.gz
cd exoharness-v0.1.0-linux-x86_64-gnu
docker pull postgres:18.6-alpine3.23
bash scripts/start-native.sh prepare-db
bash scripts/start-native.sh start
bash scripts/start-native.sh access
```

Administration: `http://127.0.0.1:9797/`. User portal: `http://127.0.0.1:9798/`. File service: `127.0.0.1:9790`. The `access` output contains local credentials.

## Requirements and scope

- Linux x86_64, **glibc 2.39 or newer**, Python 3.11+, Docker Engine and permission to use it. Validated on Ubuntu 24.04 / WSL2.
- PostgreSQL is required. The bundled native launcher provisions a local PostgreSQL container from the separately downloaded image.
- Configure a model connection and assistant before submitting model tasks. Model API credentials, Skills, external MCP services, and an OCI execution image are supplied separately. User signup requires SMTP.
- This first public release is a **prerelease**. Windows, macOS, ARM and older glibc are not verified. Container main-service deployment requires a compatible separately prepared runtime image.
- Source and core binary: AGPL-3.0-only. License and commercial licensing information are included.

## Verification

The extracted archive was tested with a fresh disposable PostgreSQL database, independent ports and private temporary credentials:

- Manifest checksums and archive inventory.
- Three HTTP health endpoints, embedded pages and authenticated configuration API.
- Session/Run persistence and signed file upload/download, Range response, and invalid signature rejection.
- Native launcher database preparation, startup, process identity checks, stop and graceful service shutdown.
- 29 tool module unit regressions and 5 native packaging tests passed.

These checks do not execute a real model, GPU generation, external MCP service, SMTP or OCI task. See the attached `release-validation.json` for the package digest and validation scope.
