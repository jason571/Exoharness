## 设计选择

服务摘要、工具选择和完整 Schema 分开。能力登记及授权快照仍覆盖整个可授权目录，模型只读取服务摘要、选择相关服务，按当前阶段加载工具。已有 Skill 指定名称时允许一次批量精确查找。无需新增前置匹配模型请求。

分页条件绑定查询和固定版本。成功选择后，旧发现页面作为历史证据留在执行日志，在模型窗口中用紧凑选择回执替代。业务内容、用户要求、Skill 根说明和后续持久化流程不依靠目录摘要恢复。

## 回归范围

- 68 工具、多个服务：初始元信息按服务聚合，选择时只加载所需 Schema。
- 查询词变化、服务变化、名称集合变化、版本变化：不沿用旧分页。
- 精确批量查询：完整匹配、缺失项、跨服务重名、未授权服务、激活原子性。
- 多页历史：选择后精简，新增查询保留，完整日志与业务 JSON 不变。
- 真实 HTTP API、协议 MCP、PostgreSQL、缓存 OCI 沙盒：选择、执行、持久化下一步和交付。
- 既有课件、配音、图片、歌曲、视频、网页、PPT、代码、取消、排队和未知结果回归。
