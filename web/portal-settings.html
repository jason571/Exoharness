关于我们

ExoHarness 是连接智能助理、模型与工具的通用执行平台。通过对话组织任务，让能力调用、执行进度和生成结果清晰可见。

聊天宠物

选择聊天中的陪伴角色，也可以随时关闭浮动宠物。

已安装的能力

管理员授权后，可连接远程 MCP 地址、粘贴地址型 mcpServers JSON，或从公开 GitHub 项目安装本地 MCP。Skill 只从公开 GitHub 项目安装；用户安装 Skill/MCP 不接受上传文件。远程 MCP 所需的认证信息在对应能力下填写，页面只显示“已配置”。

添加与管理资料

助理可在你的对话中检索并使用相关资料；资料只属于当前账号，不会自动分享给其他用户。

支持 DOCX、文字型 PDF（最大 4 MB），以及 UTF-8 文字文件（最大 2 MB）。DOCX 表格完整保留，PDF 不确定的表格保留版面文字并提示；暂不支持扫描件或图片 OCR。提取文字最多 1 MB。
